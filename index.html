FULL-STACK WEB APPGITHUB

CampusOS

Unified campus-life platform: events, clubs, a community feed, hackathon team-matching, resource booking and issue reporting. Supabase backend, Razorpay payments (test mode), and Jest + Playwright tests with GitHub Actions CI.

  • Six campus workflows in one app, replacing chat groups, forms and separate portals.

02
AI AGENTS · HACKATHONGITHUB

Kotlex

Multi-agent "round table" that turns a café owner's voice note in Kannada, Hindi or English into a fact-checked multilingual campaign: copy, poster and reel. Built for HACKERING 2.0 (Agentic AI track).

  • Twelve YAML-defined agents (strategist, copywriters, designer, loophole hunter) orchestrated with LangGraph and streamed live over SSE.
  • A code-only Fact Guard blocks any draft whose discount, price, days or times differ from the facts the owner confirmed, including Kannada and Devanagari digits.
  • A dependency graph regenerates only the assets a change affects; LLM router with provider fallback; 500+ offline pytest tests in GitHub Actions.
Python · FastAPI · LangGraph · SSE · Pillow · Tesseract View code ↗

Club Hub

One app for ~20 co-curricular clubs: public directory, event registration with waitlist and QR tickets, check-in, feedback, and a super-admin dashboard comparing club performance. Row-level security protects participant data.

  • Three roles: visitor, club lead and admin, each with its own views.
  • Participant data locked down with Postgres row-level security, even against direct API calls.

Aero Engine Digital Twin

Smart India Hackathon prototype: simulates a 3-UAV fleet with 13 sensors per engine, injects 9 fault types, and predicts health score and remaining life on a live Socket.IO dashboard.
